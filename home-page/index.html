cc-gateway

核心特性

为开发者打造的 Claude Code 网关，连接飞书与本地开发环境

远程控制

通过手机飞书机器人远程控制本地 Claude Code，随时随地发送指令、查看输出。

本地 CLI 聊天

交互式命令行界面，支持 Tab 补全、内联提示和命令历史，体验流畅的终端操作。

会话切换

/claude 进入 Claude 会话模式，所有输入直接转发给 Claude；/quit 退出会话。

目录选择器

/ll 打开交互式目录选择器，CLI 中使用 TUI 界面，飞书中以卡片形式展示。

守护进程模式

支持 start/stop/restart/log 命令管理后台服务，稳定运行不间断。

架构原理

简洁的三层架构，通过 WebSocket 和 HTTP 连接飞书与 Claude Code

快速安装

多种安装方式，总有一种适合你

macOS / Linux

一行命令快速安装

curl -fsSL https://raw.githubusercontent.com/caixy-plus/cc-gateway/main/install.sh | sh

Windows

PowerShell 一键安装

irm https://raw.githubusercontent.com/caixy-plus/cc-gateway/main/install.ps1 | iex

从源码编译

需要 Rust 环境

git clone https://github.com/caixy-plus/cc-gateway.git cd cc-gateway cargo build --release

快速开始

1

配置

cc-gateway config --init

初始化配置文件，设置飞书 App ID 和 Secret

2

启动

cc-gateway start

启动网关守护进程

3

开始聊天

cc-gateway

进入交互式 CLI，输入 /claude 开始与 Claude 对话
